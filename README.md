# EL JARDÍN DE CRISTAL

## Una aventura para ZX Spectrum 128K

**El jardín de cristal** es una aventura narrativa desarrollada para **ZX Spectrum 128K**, creada como parte de los proyectos de **ER_STUDIO**.

Esta versión contiene la primera demo jugable ensamblada del proyecto, dividida en cuatro partes.

---

## 🎮 Demo jugable

La aventura está distribuida en cuatro cintas `.tap`:

* **Parte 1**
* **Parte 2A**
* **Parte 2B**
* **Parte 2C**

Estas son las versiones ensambladas y preparadas para jugar:

```text
el_jardin_parte1.tap
el_jardin_parte2a.tap
el_jardin_parte2b.tap
el_jardin_parte2c.tap
```

Cada cinta contiene su **cargador, pantalla de presentación y juego ensamblado**, preparada para reproducir la experiencia de carga del ZX Spectrum.

---

## 🕹️ Cómo jugar

Los archivos `.tap` pueden utilizarse con un emulador compatible con ZX Spectrum, como **ZEsarUX**.

Carga la cinta correspondiente y deja que el proceso de carga se complete.

La pantalla de presentación utiliza el formato `.SCR` del ZX Spectrum y reproduce el característico sonido y efecto de carga de una cinta real.
